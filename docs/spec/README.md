# Suiss Relay — Canonical Specification

**Tarih:** 2026-10-08
**Karar sahibi:** Adem

Bu klasör Relay'in kanonik spec'idir. Spec ana bölüm başına bir dosyaya bölünmüştür. Bölünme içeriği, § numaralarını ve ID'leri değiştirmez; çapraz atıflar § numarası ve ID ile yapılır (ör. "§19.6", "T-10"); Access spec'ine atıflar "Access " önekiyle yapılır (ör. "Access OP-73"). İlk okuma için önce **Kısaca Relay**'i, sonra **Okuma rehberi**'ni okuyun. Açık sorular §22'dedir; karar verilmemiş bir konuda implementasyon karar vermez (§3.6).
